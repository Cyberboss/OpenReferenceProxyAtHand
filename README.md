# OpenReferenceProxyAtHand

A [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader) mod for [Resonite](https://resonite.com/) that changes `ReferenceProxy`'s opening of inspectors from in front of your face to in front of the hand that opened it.

## Installation
1. Install [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader).
1. Place [CustomJoinVerifierWhitelist.dll](https://github.com/Cyberboss/OpenReferenceProxyAtHand/releases/latest/download/OpenReferenceProxyAtHand.dll) into your `rml_mods` folder. This folder should be at `C:\Program Files (x86)\Steam\steamapps\common\Resonite\rml_mods` for a default Windows install. You can create it if it's missing, or if you launch the game once with ResoniteModLoader installed it will create this folder for you.
1. Start the game. If you want to verify that the mod is working you can check your Resonite logs.
